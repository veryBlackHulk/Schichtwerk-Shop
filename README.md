# Schichtwerk-Shop

## Produkt-Agent

- `agent/ANLEITUNG.md` – alle Regeln, nach denen der Agent Produkte von MakerWorld vorschlägt (Lizenz, Kobra X, PLA-Farben, Preis, Beschreibung).
- `agent/preis.mjs` – rechnet den fairen Preis: `node agent/preis.mjs --minuten 95 --gramm 31 --markt 4.99,6.50`
- `vorschlaege/liste.json` – die Vorschläge. Im Shop unter **Verwalten → Vorschläge** übernehmen oder verwerfen.
